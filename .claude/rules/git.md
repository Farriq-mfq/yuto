# Git rules
- Small commits, one purpose each. Message: `type: short summary` (`feat`, `fix`, `test`, `docs`, `chore`, `refactor`).
- Branch per phase task: `feat/<short-name>`.
- Never push or force-push without being asked.
- Do not commit generated build output, `.env`, or `node_modules`.
- Schema changes and their migration SQL go in the same commit.
